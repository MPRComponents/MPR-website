# MPR — Making Performance Real

A lightweight static website for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository, e.g. `mpr-website`.
2. Upload everything in this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will give you the Pages URL.

## Before publishing

Open `index.html` and replace:

`REPLACE-WITH-YOUR-EMAIL@example.com`

with the email address you want the contact button to use.

The two supplied logos are already included in `assets/`.
